## 一、用 AI 高效读懂 GitHub 项目

GitHub 上有很多优秀的项目，我们可以复刻或者是学习。但是如何去学习或者快速了解这些项目是一个问题。

有些人可能说把它下载下来，或者克隆到本地，然后用 AI 去解读一下。但是对于那种过于庞大的项目，AI 解读起来可能也比较费劲。

所以我去探究了一下如何比较省时省力地去学习一个 GitHub 项目，找到了下面三个网站：

1、智谱的 zread：https://zread.ai/

![zread 网站界面](/images/ai-resources-sharing-2/01.png)

zread 首页

2、DeepWiki：https://deepwiki.com/

![DeepWiki 网站界面](/images/ai-resources-sharing-2/02.png)

DeepWiki 首页

3、Google的CodeWiki：https://codewiki.google/

![CodeWiki 网站界面](/images/ai-resources-sharing-2/03.png)

CodeWiki 首页

它们的共同点在于：

1. 你可以通过 GitHub 项目的名称或地址去搜索项目仓库，进而学习这些项目。
2. 这些网站都内置了 AI，支持通过和 AI 聊天的方式来了解项目内容。
3. 它们都针对一些 Star 数较高、比较知名的关键项目做了专门的解读。
4. 而且这三个网站都有对 GitHub 项目的概览图。

不同点如下：

1. 智谱的网站（zread）支持中英文两种语言。
2. 谷歌的网站（CodeWiki）推出时间最晚，一些 Star 数较低（比如有些 10K 左右的项目）的项目可能尚未被收录。

这三个网站目前有一个共同的缺点，就是更新速度较慢。虽然现在已经是 5 月 16 号，很多项目都发生了更新，但它们收录的内容可能还停留在 4 月初或 4 月末。不过这种情况也无所谓，并不妨碍用户去学习这些项目。

第二个和第三个网站由于都是全英文界面，对于英文不好的朋友，我建议搭配“沉浸式翻译”这个浏览器插件去学习这些项目。

## 二、用 AI 快速生成 HTML 幻灯片

最近 AI 圈比较火的就是用 HTML 网页去做演示文稿，也涌现出了非常多的 GitHub 项目，比如宝玉、归藏、还有张zara 等大佬贡献的项目。

首先，这个网站（https://agentskillshub.top）收录了 GitHub 中的各种各样的项目。

这个界面（https://agentskillshub.top/best/ppt-presentation/）是他收录的一些关于 PPT 的 skill 库仓库界面，不过我个人认为收录得不是很全。

所以我挑几个我认为一定要看、一定要用的做 PPT 的 skill。

当然，这些 skill 的功能可能非常强大，不仅仅可以做 PPT，还可以做一些设计图、科研配图等等。

而且如果你想学习这些 skill 库的一些写法和技巧，可以配合我在上面分享的那三个学习 GitHub 项目的网站来学习。
