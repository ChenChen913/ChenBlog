# 写法速查

## Frontmatter 字段

```
title: "文章标题"            # 必填
title_en: "English Title"    # 可选，英文模式下显示
date: "2025-12-10"           # 必填，格式 YYYY-MM-DD，决定排序
category: "tech"             # 必填，12 选 1：tech/life/reading/AI/product/
                              # career/finance/travel/food/music/movie/game
tags: ["标签1", "标签2"]      # 可选；有共同标签的文章互为「相关文章」
draft: true                   # 草稿标记，正式发布时删除此行
```

## 图片

只接受站内绝对路径（放在 `public/images/` 下）或 https 外链：

```
![图片描述](/images/分类目录/01.png)
```

## 图片说明（重要约定）

**「只含一张图片的段落」紧跟「一行短文本」时，短文本自动渲染为图片说明**
（紧贴图片正下方、小字、淡色、居中，由 rehype-figure-caption 插件处理）：

```
![图片描述](/images/xxx/01.png)

网图
```

上例中「网图」两个字会成为这张图片的说明文字。

规则要点：

- 图片与说明各自是独立段落，中间隔一个空行；
- 说明文字不超过 40 字，超过则按普通正文段落渲染；
- 不是每张图都必须有说明，按需添加即可。

## 其他常用语法

- 引用块：`> 引用内容`
- 代码块：三个反引号 + 语言标记
- 数学公式：`$行内$` / `$$块级$$`
