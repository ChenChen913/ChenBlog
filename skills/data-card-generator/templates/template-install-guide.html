安装指南

Claude Code
安装与配置教程

从零开始，5 分钟完成安装，开始 AI 辅助编程

🔗
官方下载地址
https://claude.ai/download
1
安装 Node.js（必须 v18+） 命令行

打开终端，检查已安装的版本：

node --version
✅ 显示 v18.x 或以上即满足要求，否则前往 nodejs.org 更新
2
全局安装 Claude Code 命令行
npm install -g @anthropic-ai/claude-code
⚠️ Mac 用户如遇权限错误，在命令前加 sudo，Windows 需以管理员身份运行
3
进入项目目录并启动 完成

进入你的项目文件夹后运行：

cd 你的项目路径 && claude
🎉 首次启动会引导你登录 Anthropic 账号，完成后即可开始使用
