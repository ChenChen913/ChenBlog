📖 操作手册 4 个步骤

配置 Claude Code
MCP 服务器接入

让 Claude Code 连接外部工具，解锁 Slack、GitHub、数据库等能力

macOS Windows Linux
1
找到配置文件目录 必须
$open ~/.claude/
ℹ️ 若目录不存在，先运行一次 claude 命令让它自动创建
2
编辑 claude_desktop_config.json 必须

在配置文件中加入 mcpServers 字段，以 Slack MCP 为例：

// claude_desktop_config.json
{"mcpServers": {
  "slack": {
    "url": "https://mcp.slack.com/sse"
  }
}}
3
重启 Claude Code 必须
$claude --mcp-debug
⚠️ 修改配置后必须完全退出重启，热更新不生效
4
验证连接与授权 完成

启动后输入 /mcp 指令查看已连接服务，或访问授权页完成 OAuth：

🔗 https://docs.anthropic.com/zh-CN/docs/claude-code/mcp
✅ 看到服务名称旁边显示绿点即表示连接成功
