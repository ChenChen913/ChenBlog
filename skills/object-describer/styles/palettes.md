# Color Palettes (Dynamic Systems)

## 1. The 90/10 Rule (Standard)
*   **Base**: 90% Neutral (Grey, White, Black, Transparent).
*   **Accent**: 10% Brand/Subject Color.
*   **Usage**: Best for Bento Grids and Info-heavy layouts.

## 2. Monochromatic
*   **Logic**: All shades of a single hue (e.g., all Blues).
*   **Usage**: "Tech" (Blues), "Nature" (Greens), "Luxury" (Golds).

## 3. Complementary (High Contrast)
*   **Logic**: Opposites on color wheel (Orange/Blue, Red/Green).
*   **Usage**: "Pop Art", "Energetic", "Food" (Red/Green).

## 4. Analogous (Harmonious)
*   **Logic**: Neighbors on color wheel (Blue/Teal/Green).
*   **Usage**: "Calm", "Professional", "Backgrounds".

## 5. The "Void" Palette
*   **Logic**: Black + Dark Grey + One Neon Neon.
*   **Usage**: "Cyberpunk", "High-End Tech".

## 6. The "Pastel Dream" Palette
*   **Logic**: High brightness, low saturation. Pink, Baby Blue, Mint.
*   **Usage**: "Fashion", "Beauty", "Ethereal".
