# Editorial Poster / DIY Guide Template

## Layout Structure
**Format**: 4K Resolution (3840x2160px), Landscape.
**Composition**: Split Layout (Left 1/3: Showcase, Right 2/3: Steps).
**Style**: Premium Magazine / Museum Quality.

## Section Breakdown

### Top Header (8% Height)
- **Title**: "[Theme Name] Manual"
- **Subtitle**: "[Style Tag] · [Slogan]"

### Left Column (33% Width) - The Showcase
1.  **Hero Image (Upper 60%)**:
    - High-fidelity photo of the [Object Name] with [Micro-Innovation Twist].
    - Lighting: [Selected Lighting Style].
    - Material: [Selected Material].
2.  **Color Legend (10%)**:
    - Functional colors from [Selected Palette].
3.  **Materials Grid (Bottom 30%)**:
    - Visual grid of components.

### Right Column (67% Width) - Step-by-Step Guide
- **Grid**: 3x2 Layout (6 Large Panels).
- **Step Structure**:
    - **Header**: Step Number + Name.
    - **Description**: Concise instructions.
    - **Visual**: Action shot.

### Footer (5% Height)
- **Maintenance**: Icons and tips.

## Design Principles
- **Typography**: Editorial fonts.
- **Color Coding**: Only icons carry color.
- **Atmosphere**: Determined by [Lighting] and [Material].
