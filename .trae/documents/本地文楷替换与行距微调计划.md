# 本地文楷替换与行距微调计划

## Summary
本次计划的目标是：放弃当前文章区域使用的 CDN 文楷方案，改为直接使用项目内已有的本地露鹜文楷字体文件，并在保持“正文/文章标题用文楷、UI 保持无衬线”的前提下，给正文额外增加一点行距，让阅读观感更接近你之前确认过的本地 3 号字体效果。

- 你已明确确认：本次不再尝试系统安装字体名方案，而是直接采用“项目内字体文件（推荐）”作为落地方式。

## Proposed Changes
### 1. 将文章文楷方案切换为项目内本地字体
- 文件：[index.css](file:///c:/Users/11853/Desktop/个人网站/blog/src/index.css)
- 文件：[index.html](file:///c:/Users/11853/Desktop/个人网站/blog/index.html)
- 计划做法：
  - 在 `index.css` 中正式加入 `@font-face`，把一个明确的本地字体族名指向 `/fonts/lxgw/LXGWWenKai-Medium.ttf`。
  - 将 `--font-kai` 的默认值从 CDN 字体切换为本地字体族，并保留系统无衬线回退，确保加载失败时仍能回落。
  - 在 `index.html` 中移除或停用当前文楷 CDN 引入，避免本地方案与 CDN 方案叠加导致观感混乱。
- 目标效果：文章区看到的字体尽可能贴近你之前在本地测试页里确认过的 3 号字体。

### 2. 保留“文章文楷 + UI 无衬线”的混搭结构
- 文件：[index.css](file:///c:/Users/11853/Desktop/个人网站/blog/src/index.css)
- 文件：[Post.tsx](file:///c:/Users/11853/Desktop/个人网站/blog/src/pages/Post.tsx)
- 计划做法：
  - 保持 `.article-body`、文章主标题继续走 `--font-kai`。
  - 不修改导航、侧边栏、目录、时间、按钮、统计信息等 UI 字体体系，继续保留 `--font-sans`。
- 目标效果：只替换阅读内容的字体，不让整站 UI 一起变成文楷，避免界面信息变得拖沓。

### 3. 给正文增加一点点行距
- 文件：[index.css](file:///c:/Users/11853/Desktop/个人网站/blog/src/index.css)
- 计划做法：
  - 在现有基础上，对 `.article-body p` 的行距做小幅上调，而不是大改字号。
  - 同步观察 `li`、`blockquote` 等文本元素与正文的节奏是否需要微调，确保段落更松弛，但不会让页面显得发空。
  - 保持公式与代码块区域不做过度干预，避免局部排版异常。
- 目标效果：阅读时呼吸感更好，文楷字形不会因为行距偏紧显得拥挤。

### 4. 维持现有字号体系，仅做必要协调
- 文件：[index.css](file:///c:/Users/11853/Desktop/个人网站/blog/src/index.css)

- 目标效果：先解决“字体不是之前那个”的核心问题，再避免因字体切换引起标题过粗或正文过挤。

## Assumptions & Decisions
- 已锁定字体来源为项目内本地字体文件，而不是系统字体名或 CDN。
- 已锁定文章排版策略为：文章内容区使用本地露鹜文楷，UI 区继续保持无衬线。
- 已锁定微调方向为“给正文加一点点行距”，不再优先继续放大字号。
- 本次以最小改动为原则：优先修改 `index.css`，必要时补充 `index.html` 与 `Post.tsx`。
- 本次不扩展到代码字体、全站 UI 字体或字体管理面板等额外功能。
